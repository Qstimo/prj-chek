# CAIRN — компактный режим реестра проектов

> Дизайн: на главной рядом с карточками — строки с обзором; `GET /projects` отдаёт `ProjectListItem` с полями по уровню секций Info/Infra; вид по умолчанию — строки (`localStorage`).

Дата: 2026-10-26 · Основание: `project-registry-spec` (реестр проектов), ТЗ 4.1–4.3, спека этапа 1 §5.5

## 1. Зачем

Карточки удобны для малого числа проектов. При десятках сайтов сводка должна читаться как реестр: название, жизненный цикл, платформы, прод-домен, прод-сервер, статус, дата паспорта — в одной строке на проект.

## 2. Решение

- Два вида на главной: **строки** (по умолчанию) и **карточки**. Выбор в `localStorage` (`cairn.projectListView`), не на сервере.
- Статус по-прежнему из `GET /status/summary` — в list DTO не дублируется.
- `GET /projects` расширяется аддитивно до `ProjectListItem`; `ProjectMetadata` и `GET /projects/:id` не меняются.
- Прежний инвариант «list всегда Metadata» снимается: список — обзор с проекциями по секциям, полный паспорт — только detail.

## 3. Контракт `ProjectListItem`

| Поле | Условие | Иначе |
|------|---------|--------|
| `id`, `slug`, `name`, `lifecycle` | видимость проекта | — |
| `updatedAt` | Info ≥ Read | `null` |
| `platforms` | Info ≥ Metadata (порядок `position`) | `[]` |
| `productionDomain` | Infra ≥ Metadata | `null` |
| `productionServerName` | Infra ≥ Read (только имя) | `null` |

Пустая ячейка и «нет секции» неразличимы снаружи — секция не светится.

## 4. Выбор прода

- Окружение: `kind = production`; при нескольких — `name ASC`, одно.
- Домен: среди доменов этого окружения — `name ASC`, первый (как `domainsOf`).
- Нет прода / доменов / машины — соответствующие поля `null` при достаточном праве.

## 5. API

`findVisible` сортирует проекты по `name ASC` и обогащает **батчами** (grants, платформы, прод-окружения, домены, серверы) — без N+1 `levelsForProject` в цикле.

## 6. UI

- Home остаётся RSC; список и переключатель — client island.
- Initial render = `rows`; `localStorage` после mount (без мигания cards→rows).
- Строка ведёт на `/projects/:id`. Карточки без новых полей.
- На узком экране — горизонтальный скролл строк.

## 7. Вне объёма

Фильтры, серверное предпочтение вида, все окружения в строке, расширение карточек, изменения MCP.
